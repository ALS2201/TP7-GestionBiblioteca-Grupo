# TP7 - Gestión de Biblioteca

Proyecto Integrador de Programación Orientada a Objetos desarrollado en Java. El sistema administra los préstamos de libros para socios estudiantes y docentes.

## 👥 Organización del Equipo
El proyecto es desarrollado por 6 integrantes, divididos en tareas específicas:
* **Subgrupo 1 (1 integrante):** Implementación de clases `Prestamo` y `Socio`.
* **Subgrupo 2 (1 integrante):** Implementación de clases `Estudiante` y `Docente`.
* **Subgrupo 3 (1 integrante):** Implementación de clase `Libro`.
* **Subgrupo 4 (3 integrantes):** Implementación de clase `Biblioteca`.
* **Trabajo Conjunto:** Implementación de la clase final `GestionBiblioteca`.

## 🛠️ Requisitos Técnicos y Herramientas
* **Entorno de Desarrollo:** BlueJ.
* **Gestión de Tareas:** Tablero de Trello para coordinar el flujo de trabajo.
* **Reglas de Código:** Uso estricto de colecciones genéricas y todas las clases agrupadas bajo el paquete `biblioteca`.

## ⚙️ Flujo de Trabajo en Git
Para evitar conflictos de código, cada integrante debe ejecutar este ciclo en la terminal:

1. **Actualizar el proyecto (Siempre antes de programar):**
   `git pull origin main`
2. **Preparar los archivos modificados:**
   `git add .`
3. **Sellar los avances:**
   `git commit -m "Nombre: descripción breve de la tarea implementada"`
4. **Subir los cambios a la nube:**
   `git push origin main`
